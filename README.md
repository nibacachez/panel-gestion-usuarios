# 📋 Panel de Gestión de Usuarios

Una aplicación web interactiva para gestionar usuarios internos de una organización, desarrollada con HTML, CSS y JavaScript.

## ✨ Características

### 🔐 Validaciones Robustas
- **Nombre**: Solo letras y espacios (2-50 caracteres)
- **Edad**: Rango válido de 18-65 años
- **Rol**: Selección obligatoria (Administrador/Usuario)
- Mensajes de error claros y validación en tiempo real

### 📊 Estadísticas en Tiempo Real
- Usuarios activos e inactivos
- Conteo por roles (Administradores/Usuarios)
- Actualización automática al modificar datos

### 🎯 Funcionalidades
- ✅ Agregar nuevos usuarios
- 🔄 Cambiar estado (Activo/Inactivo)
- 🗑️ Eliminar usuarios con confirmación
- 🔍 Filtrar por rol (Todos/Administradores/Usuarios)
- 📈 Ordenamiento automático por edad

### 🎨 Interfaz Moderna
- Diseño responsivo con Bootstrap 5
- Gradientes y animaciones suaves
- Tema profesional con colores intuitivos
- Navegación mejorada con teclado

## 🚀 Uso

1. Abre `index.html` en tu navegador
2. Completa el formulario de registro
3. Gestiona usuarios con los botones de acción
4. Usa el filtro para visualizar usuarios específicos

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica
- **CSS3**: Estilos modernos con variables CSS
- **JavaScript (ES6+)**: Lógica interactiva
- **Bootstrap 5**: Framework CSS responsivo
